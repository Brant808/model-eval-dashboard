AA Intelligence Index v4.1

What it measures
The broadest independent composite score for overall model capability, published by Artificial Analysis. It answers the page's headline daily question: who leads the frontier race, and did the order change overnight? It also feeds the default column choice, so it is the page's reference ranking.
Harness & version
Artificial Analysis runs its own evaluations against first-party endpoints; the current index version is v4.1, confirmed current as of the 2026-08-01 source check (source S1). Collection uses AA's documented Data API v2, with the models page's embedded JSON as fallback.
Cadence & freshness
AA updates same-day or next-day on model releases and refreshes performance data daily; this page treats the figure as stale after 72 hours.
Independence
Independent evaluator with disclosed lab-revenue exposure: AA sells enterprise insight subscriptions and private custom benchmarking to AI companies, so ranked labs can be paying customers, separated from the public leaderboard only by AA's stated policy ('no one pays to be on the leaderboard') and mystery-shopper accounts (source S1).
